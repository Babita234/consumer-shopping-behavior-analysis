# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior for a retail company. The objective is to understand purchasing patterns, identify key drivers behind customer decisions, and generate insights that can help improve marketing strategies, product offerings, and customer engagement.

The analysis combines Python for data preparation, SQL for querying and analysis, and Power BI for visualization and dashboard creation.

## Business Problem

A retail company wants to better understand its customers’ shopping behavior. The company has observed changing purchasing patterns across demographics, product categories, and sales channels.

The key question addressed in this project is:

How can the company use consumer shopping data to identify trends, improve customer engagement, and optimize marketing and product strategies?

## Dataset

The dataset includes information related to customer purchases such as:

Customer demographics
Product categories
Purchase amounts
Discounts
Product reviews and ratings
Payment methods
Online vs offline purchases
Seasonal sales patterns

This data helps identify patterns in consumer behavior and purchasing decisions.

## Project Workflow

### Data Preparation and Cleaning (Python)

The dataset was loaded and prepared using Python.

Key tasks included:

Handling missing values
Removing duplicates
Formatting and transforming columns
Preparing the dataset for analysis

### Exploratory Data Analysis

Exploratory analysis was performed to understand:

Customer demographics distribution
Product category performance
Purchasing trends across time
Customer buying behavior

### Data Analysis using SQL

SQL queries were used to analyze the dataset and extract insights such as:

Customer segmentation
Purchase frequency
Top selling product categories
Payment method preferences
Repeat purchase behavior

### Data Visualization (Power BI)

An interactive dashboard was created in Power BI to visualize important insights including:

Sales trends
Customer demographics
Online vs offline purchasing patterns
Product category performance
Impact of discounts on purchases

## Key Insights

Important findings from the analysis include:

Discounts significantly influence purchasing behavior
Certain product categories consistently generate higher sales
Online shopping channels show growing adoption
Some customer segments demonstrate higher loyalty and repeat purchases

## Business Recommendations

Based on the analysis, the following recommendations were identified:

Use targeted marketing strategies for high value customer segments
Optimize discount strategies to improve conversion rates
Focus inventory planning on high demand product categories
Improve the online shopping experience to increase engagement
